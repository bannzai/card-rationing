## 前提と制約

- 生成画像のため、カードの枚数・印の数・細部は画像ごとに揺れる。見てほしいのは画風・色・質感・画面の密度で、配置や数値ではない
- 文字は入れていない (ゲーム名が決まっていないことと、生成画像の文字は崩れるため)。文字の載せ方は、方向が決まってから実装の画面で確かめる
- 使わないと決めて生成の指示に書いたもの: 平らな矩形の UI パネル、上部のメニューバー、金属・クローム・ネオンの質感、3D レンダ、アニメ調 (`~/.claude/documents/guides/visual-patterns-to-avoid.md` の「画像」と、1 回目のモックへの評価から)
- 生成に使ったプロンプトと状態 (候補・承認・却下) は同じディレクトリの `references.json` に記録している
- `.gdignore` を置いて、Godot がこのディレクトリの PNG を import しないようにしている
