# カードの残り使用回数はラン全体で持ち越す

このゲームの核は「カードの使用回数が 1 回の冒険 (ラン) を通して減り、戦闘をまたいで戻らない」ことで、強いカードを温存するか使うかのジレンマはここからしか生まれない (起票元: https://github.com/bannzai/IdeaMemo/issues/353 )。Slay the Spire 型の実装に引きずられて、戦闘の開始・終了でデッキや使用回数を初期化しない。

- 残り使用回数はラン単位の状態 (autoload) に持ち、戦闘の山札・手札・捨て札 (戦闘単位の状態) とは別に持つ。戦闘の開始・終了・リトライで残り使用回数を初期化しない
- 残り使用回数を増やす経路は、イベント・報酬・休憩など明示した経路だけにし、どの経路で増えたかを `scripts/dev/selfcheck.gd` で検証する
- 残り使用回数が 0 になったカードの扱い (契約切れとしてデッキに残し、手札に来るが使えない) と、全カードを使い切った時の扱い (常に使える基本行動「もがく」とターン終了) は `documents/DIRECTION.md`「決めたこと」に記録してある。変える時は先に同文書へ書く
